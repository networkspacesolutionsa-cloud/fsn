# مجلد السوشال ميديا — فضاء الشبكات الأمنية

تصاميم جاهزة للنشر على إنستقرام وتيك توك، مبنية على نفس هوية الموقع (اللوقو، اللون الكحلي والأزرق، خط Cairo) وبنفس أسعار الخدمات المعروضة في الموقع.

## المحتويات

```
social-media/
├─ assets/        اللوقو بكل نسخه (كامل، رمز ملون، رمز أزرق، أيقونات)
├─ instagram/     8 منشورات 1080×1350 (مقاس 4:5 الأفضل ظهورًا)
├─ tiktok/        5 أغلفة 1080×1920 (تصلح أيضًا لستوري إنستقرام وأغلفة ريلز)
├─ html/          ملفات HTML المصدرية لكل تصميم
├─ captions.md    الكابشنات والهاشتاقات وسكربتات فيديوهات تيك توك وخطة نشر
└─ build.mjs      سكربت توليد الصور
```

## قبل النشر

**رقم التواصل غير موجود في التصاميم عمدًا.** الرقم الموجود في بيانات الموقع (`+962 77 894 7384`) يبدو رقمًا تجريبيًا وليس رقم الرياض، فاعتمدت على رابط الموقع `fsn-networks.sa` بدلًا منه. أعطني الرقم الصحيح وأضيفه على كل التصاميم خلال دقيقة.

وفي `captions.md` استبدل `[رقم الجوال]` بالرقم الفعلي.

## تعديل التصاميم أو إضافة منشور جديد

كل النصوص والأسعار موجودة في `build.mjs` داخل مصفوفتي `IG` و `TT`. عدّل النص أو السعر أو أضف عنصرًا جديدًا، ثم:

```bash
node social-media/build.mjs
```

يعيد توليد كل الصور خلال ثوانٍ. (يتطلب وجود Google Chrome على الجهاز، وهو ما يستخدمه السكربت للتصوير.)

خيارات كل منشور:

| الحقل | الوظيفة |
|---|---|
| `file` | اسم الملف الناتج |
| `theme` | `'light'` لخلفية فاتحة (الافتراضي كحلي) |
| `eyebrow` | الشريط الصغير فوق العنوان |
| `title` | العنوان (`<br>` لكسر السطر) |
| `titleSize` | حجم العنوان عند الحاجة |
| `sub` | الجملة التوضيحية |
| `price` / `priceNote` | بطاقة السعر |
| `rows` | جدول أسعار `{n, s, p}` |
| `bullets` | النقاط مع علامة ✓ |
| `footnote` | التنويه الصغير (الاستثناءات) |
| `cta` | عبارة الحث في الفوتر |

## ملاحظات على المقاسات

- **إنستقرام:** 1080×1350 هو المقاس الذي يأخذ أكبر مساحة في التايم لاين. منشور قائمة الأسعار (`ig-07`) مصمم ليُحفظ ويُعاد إرساله للعملاء.
- **تيك توك:** المحتوى كله داخل المنطقة الآمنة (فوق 150 بكسل وتحت 430 بكسل من الأسفل) حتى لا تغطيه أزرار التطبيق والكابشن.
- الأغلفة الرأسية تصلح كما هي لستوري إنستقرام وسناب شات.
